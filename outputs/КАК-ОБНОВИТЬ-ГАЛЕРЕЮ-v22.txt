Исправление галереи на компьютере — v22

Готовый index.html уже находится в корне рабочей папки репозитория. Чтобы опубликовать исправление:

1. Откройте в GitHub Desktop репозиторий drevesny-zamysel-site-upgrade из этой папки.
2. На вкладке Changes оставьте выбранным только index.html. Файлы из outputs и удаление outputs/gallery-fix-v20/index.html в этот commit не включайте.
3. В Summary напишите «Исправлена галерея на компьютере» и нажмите Commit to main.
4. Нажмите Push origin.
5. После публикации откройте сайт на компьютере и обновите страницу через Ctrl+F5.

Если GitHub Desktop открыт на другой копии репозитория, возьмите index.html из этого архива и замените им файл в корне той копии, затем выполните шаги 2–5.

В настольной галерее фото помещаются целиком в одинаковые плитки. Нажатие открывает крупный просмотр; листать можно экранными кнопками или стрелками клавиатуры. Мобильные стили этой правкой сохранены.
