Исправление галереи на компьютере — версия 24

В этой версии плитки больше не задают фотографиям рамку 4:3 и не растягивают изображение на её высоту. Фото показываются целиком в исходных пропорциях и на компьютере, и на телефоне.

Публикация:
1. В GitHub Desktop откройте репозиторий drevesny-zamysel-site-upgrade из папки сайта.
2. Распакуйте gallery-desktop-fix-v24.zip в корень репозитория с заменой index.html (либо используйте уже исправленный index.html из корня рабочей папки).
3. Убедитесь, что для commit выбран только index.html. Не включайте outputs и другие ожидающие изменения.
4. Сделайте commit и нажмите Push origin.
5. Дождитесь обновления GitHub Pages и обновите страницу галереи с Ctrl+F5.
