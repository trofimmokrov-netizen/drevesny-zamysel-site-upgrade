Исправление галереи на компьютере — v26

Причина: опубликованный GitHub Pages всё ещё подключает старую версию стилей галереи v19. Новый локальный index.html содержит исправление v36. ZIP включает только этот index.html; телефонные правила галереи сохранены.

Как опубликовать:
1. Распакуйте gallery-desktop-fix-v26.zip.
2. Скопируйте index.html из архива в корень репозитория drevesny-zamysel-site-upgrade, заменив старый index.html.
3. Откройте GitHub Desktop и проверьте, что изменился index.html.
4. Введите сообщение коммита: Исправлена галерея на компьютере.
5. Нажмите Commit to main, затем Push origin.
6. Дождитесь завершения GitHub Pages. Откройте сайт и обновите Ctrl+F5.

Важно: загружать нужно именно в корень репозитория, где лежит index.html, не в папку outputs. После публикации в исходном коде страницы должна быть ссылка interaction-polish.css?v=20261110-gallery-v36. Если остаётся v19, новая версия ещё не опубликована или браузер показывает старую страницу.
