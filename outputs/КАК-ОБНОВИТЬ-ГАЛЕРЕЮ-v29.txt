Обновление галереи v29

Причина: на опубликованной GitHub Pages странице всё ещё используется старая версия стилей gallery-v19. Новый вид галереи должен отображать равномерные карточки на компьютере и целиком показывать фотографии без обрезки. На телефоне текущая раскладка остаётся без изменений.

Как опубликовать:
1. Распакуйте gallery-desktop-fix-v29.zip.
2. Скопируйте находящийся внутри index.html в корень репозитория drevesny-zamysel-site-upgrade, заменив старый index.html.
3. В GitHub Desktop проверьте, что изменился именно корневой index.html. Введите сообщение «Исправлена галерея на компьютере» и нажмите Commit to main, затем Push origin.
4. Дождитесь обновления GitHub Pages и откройте сайт с жёстким обновлением Ctrl+F5.

Проверка новой версии: в исходном HTML должен быть параметр gallery-v39. Если остаётся gallery-v19, на GitHub ещё не опубликован новый корневой index.html.
