ОБНОВЛЕНИЕ ГАЛЕРЕИ НА КОМПЬЮТЕРЕ

1. Распакуйте gallery-desktop-fix-v27.zip.
2. Скопируйте index.html из архива в корневую папку репозитория drevesny-zamysel-site-upgrade, заменив существующий index.html.
3. В GitHub Desktop проверьте, что изменился index.html. Введите комментарий «Исправлена сетка галереи на компьютере», нажмите Commit to main, затем Push origin.
4. После публикации откройте сайт и обновите страницу сочетанием Ctrl+F5. GitHub Pages должен отдавать interaction-polish.css с меткой gallery-v37.

На компьютере фотографии показаны в ровных карточках без обрезки; при нажатии открывается полноразмерное фото. Правила мобильной версии сохранены.
