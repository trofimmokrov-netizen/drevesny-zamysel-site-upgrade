ИСПРАВЛЕНИЕ ГАЛЕРЕИ ДЛЯ КОМПЬЮТЕРА

1. Распакуйте оба файла из gallery-desktop-fix-v34.zip в корень репозитория drevesny-zamysel-site-upgrade, подтвердите замену.
2. В GitHub Desktop должны появиться изменения index.html и assets/css/interaction-polish.css.
3. Создайте commit и нажмите Push origin.
4. После публикации откройте сайт и нажмите Ctrl+F5. В инструментах разработчика в исходнике index.html должна быть версия desktop-gallery-v46.

Изменение исправляет сетку галереи на компьютере и загружает оптимизированные WebP напрямую по мере прокрутки, без обращения к отсутствующей папке миниатюр. Мобильную галерею не меняет. Клик по фото по-прежнему открывает просмотр полного изображения.
