Галерея для компьютера — пакет v32

В опубликованной версии пока оставались старые HTML/CSS, поэтому предыдущие исправления не появлялись. В этом пакете вместе собраны актуальные index.html, assets/css/interaction-polish.css и миниатюры галереи.

Как применить:
1. Распакуйте архив именно в корень репозитория drevesny-zamysel-site-upgrade, сохраняя структуру папок и заменяя index.html и CSS.
2. В GitHub Desktop проверьте изменения, создайте commit и нажмите Push origin. Если загружаете через сайт GitHub, загрузите файлы из распакованного архива с сохранением путей, а не сам ZIP.
3. Дождитесь обновления Pages, затем откройте страницу галереи на компьютере и обновите её через Ctrl+F5.

Теперь HTML использует новый номер версии CSS, чтобы браузер не оставил старый файл в кеше. Фото в сетке целиком помещаются в превью; нажатие открывает полное фото для просмотра.
