Исправление галереи на компьютере — v23

В рабочей копии исправление уже находится в корневом index.html. В опубликованной GitHub Pages версии сейчас всё ещё используется галерея v19, поэтому прежнее исправление не появилось на сайте.

Публикация через GitHub Desktop:
1. Откройте репозиторий drevesny-zamysel-site-upgrade именно из папки, которая публикуется на GitHub Pages.
2. В разделе Changes выберите только index.html. Файлы из outputs и уже существующее удаление outputs/gallery-fix-v20/index.html не добавляйте.
3. В Summary укажите «Исправлена галерея на компьютере», нажмите Commit to main, затем Push origin.
4. После завершения публикации откройте сайт и обновите его через Ctrl+F5.

На компьютере фотографии будут располагаться в одинаковых карточках, целиком помещаться внутрь без обрезания и открываться в крупном просмотре по клику. На телефоне существующая компоновка сохранена.
