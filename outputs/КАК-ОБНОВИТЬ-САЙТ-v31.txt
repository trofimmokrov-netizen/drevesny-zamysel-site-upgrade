Обновление сайта v31: галерея и адаптивные карточки партнёрства

В пакете:
- index.html с десктопной галереей, которая показывает фотографии целиком, и мобильной раскладкой карточек партнёрства: одна колонка на телефонах, две на узких планшетах;
- assets/images/portfolio/thumbnails — лёгкие миниатюры галереи. Полные фото сохраняются для увеличенного просмотра.

Установка:
1. Распакуйте архив в корень репозитория drevesny-zamysel-site-upgrade с заменой index.html и добавлением папки assets/images/portfolio/thumbnails.
2. В GitHub Desktop проверьте изменения, затем Commit to main и Push origin.
3. После публикации обновите страницу на телефоне и компьютере. Для компьютера используйте Ctrl+F5.

Исправления в локальной папке сами по себе не меняют опубликованный GitHub Pages сайт до Push origin.
