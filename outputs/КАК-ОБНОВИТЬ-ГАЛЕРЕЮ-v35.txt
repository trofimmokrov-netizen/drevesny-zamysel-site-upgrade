ИСПРАВЛЕНИЕ ГАЛЕРЕИ НА КОМПЬЮТЕРЕ

В архиве два файла с уже правильными путями:
- index.html — заменить в корне репозитория;
- assets/css/interaction-polish.css — заменить по этому пути.

После загрузки обоих файлов в репозиторий сохраните изменения и нажмите Push origin в GitHub Desktop (или Commit changes и Push, если загружаете через сайт GitHub). Подождите, пока GitHub Pages обновится. Затем откройте сайт заново и сделайте жёсткое обновление страницы: Ctrl+F5.

Проверка опубликованной версии показала, что сейчас сайт ещё отдаёт старую разметку галереи (CSS-метка v19); новые настольные правила пока не опубликованы.
