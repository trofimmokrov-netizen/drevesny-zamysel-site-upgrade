Галерея компьютера — обновление v73

В GitHub Pages пока опубликована старая версия v19. Поэтому изменения из папки проекта на сайте не видны.

Чтобы исправить галерею, загрузите в корень GitHub-репозитория файлы из архива, сохранив структуру:
- index.html — заменить существующий файл;
- assets/css/interaction-polish.css — заменить существующий файл.

Этот пакет использует оригинальные фотографии и для компьютера, и для телефона. В сетке фото целиком помещаются в карточки; клик открывает просмотр полного изображения. Миниатюры для этой версии не требуются.

После загрузки дождитесь публикации GitHub Pages. На компьютере откройте сайт и нажмите Ctrl+F5. Проверить обновление можно в исходном коде страницы: ссылка на interaction-polish.css должна содержать версию 20261111-desktop-gallery-v73.
