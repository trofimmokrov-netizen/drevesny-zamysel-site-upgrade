Обновление галереи v67

В архиве только два файла для сайта:
- index.html
- assets/css/interaction-polish.css

Как загрузить:
1. Распакуйте архив.
2. Загрузите index.html в корень репозитория и подтвердите замену.
3. Загрузите assets/css/interaction-polish.css по тому же пути и подтвердите замену.
4. Дождитесь окончания публикации GitHub Pages.
5. На компьютере откройте сайт и нажмите Ctrl+F5. Проверьте галереи закрытых и открытых лестниц: карточки должны быть одинаковой высоты, снимки видны целиком, при наведении появляется подсказка «Открыть фото», клик открывает просмотр.

В этом выпуске меняется только отображение галереи на экранах шире 720 px. Телефонные стили оставлены без изменений. Версия CSS обновлена, чтобы браузер запросил актуальный файл.
