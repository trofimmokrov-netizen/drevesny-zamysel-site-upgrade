Обновление галереи на компьютере — v28

1. В GitHub Desktop убедитесь, что открыт репозиторий drevesny-zamysel-site-upgrade.
2. В корне репозитория замените index.html файлом из архива gallery-desktop-fix-v28.zip.
3. Сохраните изменение через GitHub Desktop: commit, затем Push origin.
4. После публикации обновите страницу сайта принудительно: Ctrl+F5. На телефоне правила галереи не меняются.

Что исправлено: на компьютере плитки получили явную высоту вместо зависимости от aspect-ratio. Фото вписывается целиком через object-fit: contain, без обрезки; крупный экран показывает 3 столбца, небольшой экран компьютера — 2.
