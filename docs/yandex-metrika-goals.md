# Цели Яндекс Метрики

Счётчик 110344922 загружается только после согласия посетителя на внешние сервисы. Скрипт `assets/js/yandex-metrika-goals.js` проверяет тот же выбор перед отправкой каждой цели. При отказе или недоступном localStorage события не отправляются.

Добавьте в настройках счётчика цели типа «JavaScript-событие» с точными идентификаторами:

| Идентификатор | Что фиксирует |
| --- | --- |
| `phone_click` | Нажатие на ссылку телефона |
| `project_request_open` | Переход из CTA к форме проекта |
| `estimate_form_open` | Нажатие «Рассчитать стоимость» и открытие формы расчёта |
| `configurator_open` | Переход в 3D-конструктор |
| `yandex_route_open` | Нажатие кнопки маршрута в Яндекс Картах |
| `training_request_open` | Открытие формы запроса об обучении |
| `partnership_request_open` | Открытие формы запроса о партнёрстве |
| `franchise_request_open` | Открытие формы запроса о франшизе |
| `training_request_prepared` | Подготовка запроса об обучении к передаче в чат |
| `partnership_request_prepared` | Подготовка запроса о партнёрстве к передаче в чат |
| `franchise_request_prepared` | Подготовка запроса о франшизе к передаче в чат |

События `*_open` показывают нажатие и открытие соответствующего интерфейса; `*_prepared` показывают подготовку текста и передачу контекста виджету. Они не означают, что посетитель отправил сообщение или что Bitrix24 принял заявку. Форма Bitrix24 встроена с другого домена, поэтому факт успешной отправки нельзя надёжно вывести из клика: для отдельной цели успешной заявки нужна поддерживаемая настройка события/страницы подтверждения на стороне Bitrix24.
