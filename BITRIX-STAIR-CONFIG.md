# Автоматическая передача конфигурации лестницы в Bitrix24

На сайте уже передаются выбранные параметры лестницы в событие встроенной CRM-формы Bitrix24 с ID 1. Для сохранения параметров в CRM нужно один раз настроить скрытое поле этой формы.

## Настройка Bitrix24

1. Откройте **CRM → Продажи → Канал продаж → CRM-формы** и выберите форму сайта с ID **1**.
2. Включите **Экспертный режим** и откройте вкладку **Значения скрытых полей**.
3. Добавьте поле **«Параметры лестницы»** для сущности, которую создаёт форма (обычно это лид). Если такого поля ещё нет, создайте строковое пользовательское поле.
4. В настройке скрытого поля укажите параметр `stair_config` и сохраните CRM-форму.
5. Код в `index.html` уже устанавливает значение `stair_config` перед отправкой формы. Эта настройка в CRM нужна один раз; без неё параметры видны на странице и копируются, но не сохраняются в заявке.

Параметры передаются, когда посетитель переходит из конструктора по ссылке **«Обсудить эту конфигурацию»**. В CRM они сохраняются вместе с заявкой после отправки формы. Кнопка копирования остаётся запасным способом передать настройки менеджеру.

## Проверка

Откройте конструктор, измените материал или размеры, нажмите **«Обсудить эту конфигурацию»** и отправьте тестовую заявку. В созданной записи CRM проверьте поле **«Параметры лестницы»**. До настройки скрытого поля значение будет отображаться на странице и копироваться кнопкой, но Bitrix не сохранит его в CRM.

Bitrix24 описывает установку обработчика `b24:form:init` и заполнение скрытых полей через `form.setProperty()` в актуальной справке: [Работа с кодом CRM-формы](https://helpdesk.bitrix24.com/open/13905018/). Добавление и настройка поля описаны в статье [Значения скрытых полей CRM-форм](https://helpdesk.bitrix24.com/open/25769127/). Обработчик на сайте размещён перед кодом встраивания формы, как рекомендует Bitrix24.
