# Раздел статей и комментарии

## Статьи

- Главная показывает девять коротких анонсов.
- Полный список находится по адресу `/articles/`.
- Каждая статья — отдельный статический `index.html` со своим canonical URL, метаописанием, Open Graph данными, изображением и JSON-LD `Article`.
- Новые адреса перечисляются в `sitemap.xml`.

Страницы статические, поэтому GitHub Pages может индексировать их без сборки приложения.

## Комментарии

Сайт размещён на GitHub Pages и не имеет серверной базы данных. Поэтому HTML-форма сама по себе не сможет безопасно сохранять и публиковать комментарии между посетителями. Нужен внешний сервис обсуждений или отдельный backend с хранением, защитой от спама и модерацией.

В каждой статье подготовлено единое место для виджета. Сейчас там показано честное сообщение о подключении: форма не имитирует отправку и не собирает адреса почты, пока хранилище не настроено.

Для нужного сценария следует выбрать сервис, который поддерживает гостевой комментарий без регистрации, поле email, скрытие email от читателей и обязательную премодерацию. Перед подключением нужно зарегистрировать домен, получить embed snippet, выключить требование имени/аккаунта (если сервис это позволяет), включить премодерацию и добавить политику обработки адреса почты. После получения snippet его можно подключить общим скриптом на страницах `/articles/*`.

Документация рассмотренных решений:

- [Comentario: установка и встраивание](https://docs.comentario.app/en/configuration/embedding/) — нужен отдельный сервер Comentario; анонимные комментарии поддерживаются, но пользовательский сценарий email-only нужно подтвердить в настройках конкретного инстанса.
- [Disqus: гостевые комментарии](https://help.disqus.com/en/articles/1717211-guest-commenting) — аккаунт Disqus посетителю не нужен; email требуется и комментарии проходят ручное одобрение. Нужно проверить форму гостя и требования к отображаемому имени до выбора.

Сервис не выбран автоматически, потому что его политика email и форма регистрации определяют, совпадёт ли реальный сценарий с пожеланием «только почта и текст». Не вставляйте секретные ключи в HTML или JavaScript статического сайта.
