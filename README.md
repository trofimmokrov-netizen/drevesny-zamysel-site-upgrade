# Древесный Замысел — сайт

Это статический сайт: сборка через npm не нужна. GSAP, ScrollTrigger и Three.js уже лежат в `assets/vendor`, поэтому `node_modules` в репозиторий добавлять не нужно.

## Локальный просмотр

Для обеих страниц используйте локальный веб-сервер: так браузер корректно загрузит ES-модули, библиотеки и текстуры 3D-конструктора:

1. Откройте PowerShell в папке репозитория.
2. Выполните:

   ```powershell
   python -m http.server 8000
   ```

3. Откройте `http://localhost:8000/` — главная страница.
4. Откройте `http://localhost:8000/constructor.html` — 3D-конструктор.
5. Чтобы остановить сервер, вернитесь в PowerShell и нажмите `Ctrl+C`.

## Публикация через GitHub Desktop

1. Откройте репозиторий `drevesny-zamysel-site-upgrade` в GitHub Desktop.
2. Во вкладке **Changes** просмотрите список изменённых файлов. Для этого сайта не добавляйте папку `node_modules`.
3. Введите короткое описание в поле **Summary**, например `Обновление конструктора и мобильной версии`.
4. Нажмите **Commit to main**, затем **Push origin**.
5. После отправки изменений GitHub Pages обновит сайт. Статус публикации можно посмотреть во вкладке **Actions** репозитория.

Если GitHub Pages ещё не включён: откройте **Settings → Pages** и выберите публикацию из ветки `main`, папка `/(root)`.

## Основные файлы

- `index.html` — главная страница, галереи и встроенная форма Bitrix24.
- `constructor.html` — страница 3D-конструктора.
- `assets/js/stair-configurator.js` и `assets/css/stair-configurator.css` — логика и оформление конструктора.
- `assets/js/site-animations.js` — умеренные GSAP-анимации с поддержкой настройки уменьшения движения.
- `assets/vendor/` — локальные библиотеки GSAP, ScrollTrigger и Three.js.
- `BITRIX-STAIR-CONFIG.md` — настройка скрытого поля для сохранения конфигурации лестницы в CRM.

## Приветствие Bitrix24 на телефонах

Карточка приветствия Bitrix24 может показываться поверх первого экрана. На телефонах сайт ограничивает её ширину примерно до 205 px и уменьшает текст. Для лучшего результата также укоротите приветствие и задайте задержку в настройках Bitrix24:

1. В Bitrix24 откройте **CRM → Продажи → Каналы продаж → Виджет на сайте** и выберите подключённый виджет.
2. В автоматическом приветствии замените длинный текст на короткий, например: «Здравствуйте! Поможем с лестницей. Напишите нам».
3. Поставьте задержку 8–10 секунд. Сам виджет оставьте видимым на мобильных устройствах, чтобы клиент мог открыть чат кнопкой.
4. После публикации обновлённого `index.html` откройте сайт на телефоне и проверьте, что карточка не закрывает заголовок и основные кнопки.

Bitrix24 описывает [настройку автоматических приветствий и видимости виджета](https://helpdesk.bitrix24.com/open/25571971).
