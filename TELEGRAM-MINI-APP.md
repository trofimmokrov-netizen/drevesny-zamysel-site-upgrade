# Telegram Mini App — Древесный Замысел

## Статическая часть

`telegram-app.html` — адаптивная стартовая страница мини-приложения. Она ведёт в текущий 3D-конструктор, галерею, блок обучения и чат бота. В ней нет токена и нет прямых запросов к Bot API.

После публикации задайте в @BotFather кнопку меню бота (`/setmenubutton`) с адресом страницы, например:

```text
https://trofimmokrov-netizen.github.io/drevesny-zamysel-site-upgrade/telegram-app.html
```

Если сайт будет перенесён на REG.RU или собственный домен, в BotFather нужно указать новый HTTPS-адрес. Telegram Mini Apps требуют публичный HTTPS URL; параметры запуска и Telegram WebApp API документированы на [официальной странице](https://core.telegram.org/bots/webapps).

## Команды в меню Telegram

Чтобы Telegram показывал подсказки команд, настройте список у уже существующего бота:

1. Откройте `@BotFather` и отправьте `/setcommands`.
2. Выберите `@drevesnyzamysel_bot`.
3. Отправьте команды в формате `команда - описание`:

```text
start - Открыть меню
ladder - Собрать лестницу
training - Обучение столярному делу
partnership - Сотрудничество
help - Помощь и контакты
```

Они должны появляться в подсказках, когда пользователь вводит `/` в чате с ботом. Для запуска мини-приложения используйте отдельную настройку кнопки меню через `/setmenubutton`; список команд сам по себе её не создаёт. Если подсказки не появились сразу, заново откройте чат с ботом и проверьте после обновления Telegram.

### Если список команд не появился

1. В `@BotFather` повторно выполните `/setcommands` и внимательно выберите именно `@drevesnyzamysel_bot`.
2. Отправьте весь список одним сообщением в указанном формате и дождитесь подтверждения BotFather. Для команд указываются имена без начального `/`.
3. В чате с ботом откройте меню команд или введите `/`. Если подсказок нет, перезапустите Telegram и проверьте снова. В группах команда может быть скрыта настройкой приватности бота; проверяйте сначала в личном чате.
4. Если команды видны, но бот молчит после выбора, список настроен, а обработчик команды не отвечает. Это отдельная серверная часть; статические файлы сайта её не запускают.

Регистрация команд добавляет только пункты интерфейса. Чтобы бот отвечал на `/ladder`, `/training`, `/partnership` и `/help`, на сервере должны быть реализованы обработчики этих команд.

## Бот и обработчики команд

Сейчас в этой папке нет исходников Telegram-бота или серверной функции, которая принимает обновления Telegram. Поэтому обработчики команд и отправку заявок в Bitrix нельзя реализовать в статическом HTML. Для этого нужно добавить в репозиторий код бота либо указать отдельный репозиторий/сервер.

Для первого запуска обработчики должны отвечать на `/start`, `/ladder`, `/training`, `/partnership` и `/help`. Команды `/ladder`, `/training` и `/partnership` могут отправлять ссылки на соответствующие разделы Mini App или готовить запрос менеджеру.

Кнопка «Обсудить проект» уже открывает чат с параметром `start=project`; бот должен обработать этот payload. Другие сценарии можно добавить с отдельными payload для обучения и партнёрства. Для передачи заявок в Bitrix нужен серверный обработчик с проверкой подписи Telegram Web App `initData` и серверной авторизацией Bitrix.

## Секреты и безопасность

- Не помещайте токен Telegram, Bitrix webhook или ключи в HTML, JavaScript, GitHub Pages или коммиты.
- Храните новый токен только в переменных окружения на сервере и ограничьте доступ к ним.
- Токен, опубликованный в переписке, следует отозвать в @BotFather и заменить. Новый токен не нужно отправлять в чат.
- Перед записью в CRM проверяйте Telegram `initData` на сервере, ограничивайте поля и не доверяйте переданным клиентом данным пользователя.

## Примерка в камере

Кнопки камеры в текущем 3D-конструкторе пока нет. Это отдельная функция: сначала нужно получить упрощённую модель лестницы и подобрать AR-формат с проверкой поддерживаемых устройств. WebXR AR доступен не во всех сочетаниях браузера и устройства, поэтому необходимо оставить обычный 3D-режим как резервный. Токен и доступ к камере для прототипа не требуются.
